Compose Desktop · adb · MCP

AndroidWorld: one desktop app for every Android device.

A Compose Multiplatform desktop app for working with Android devices and emulators: logcat with filters, app data, quick toggles, screen share and AVD management. Its MCP server lets Claude Code see and drive the selected device.

ⓘ

From GitHub Releases: a Windows installer (MSI, per-user, no admin prompt). It needs adb on PATH, and scrcpy for screen share. macOS and Linux: build from source with JDK 21.

Features

What it does

Devices

Device list and facts, current app controls and screenshots.

Logcat

Level, search and package filters.

App data

Shared preferences and an SQLite editor, permissions and deep links.

Quick toggles

Font scale, density, locale, location, proxy and emulator network throttle.

Screen share

Mirror and record the device with scrcpy.

Emulators

List, start, stop, create and delete AVDs.

MCP server

Screenshots, UI tree, tap, type and swipe, apps, prefs, databases and logcat for coding agents, with a one-click Claude Code connection.

Credits

Builds on AndroidDeveloperToolkit (Device Cockpit) and ports parts of Oh My Android, used with their authors' permission.
