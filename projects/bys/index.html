BulkYoutubeSearch: a whole song list, found at once.

Give it a list of song names; it finds each one on YouTube in the background and keeps the matches as a playable library with search, artist filters, sorting and a full-screen player.

Features

What it does

Bulk search

Pick a JSON list of song names; a WorkManager job searches YouTube for each, rotating across your API keys when one runs out of quota.

Found songs

Search by song or artist, filter by one or more artists, and sort by name, artist or release date.

Release dates

Taken from YouTube, and filled in for older finds with one call per 50 songs.

Player

Plays in the app, shrinks to picture-in-picture, and goes full-screen landscape.

API keys

Add, see and remove YouTube Data API keys in the app.

Try BulkYoutubeSearch

Free and open source. Install it from the latest release, or read and build the code.
